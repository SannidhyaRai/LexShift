# Flat clustering: K-means over tf-idf judgment vectors

Generated by `python -m m4_rank.cluster build` from M1's index (every number below is computed, none is typed in).

* 4819 judgments, 2000 terms (top by df with 10 <= df <= 50% of N, digits-only terms left out); 0 judgments contain none of them.
* K-means with k-means++ seeding, 3 restarts (seeds 0..2), at most 100 iterations; the lowest-RSS run is kept.
* **K = 12** (elbow). Elbow of the RSS curve: K = 12. AIC (RSS + 2MK, M = 2000): K = 2.
* Final run: RSS = 3802.68, 30 iterations, converged = True, empty clusters refilled = 0.

The curve is shallow: RSS falls by only 8.0% from K = 2 to K = 30, as is usual for sparse, high-dimensional text vectors, so the elbow is a weak preference rather than a sharp knee.

With unit-length vectors RSS is at most N, while the AIC penalty grows by 2M per cluster, so with thousands of dimensions the textbook AIC favours the smallest K on the grid. We report it as IIR defines it and choose K by the elbow, which uses only the RSS curve. Neither criterion looks at a label or a query.

## Evaluation against the dominant offence (automatic labelling, not a human gold standard)

Each judgment's class is the offence_id with the most references in M2's `doc_statutes.jsonl`. 4041 judgments have one (37 classes); 778 have no offence reference and are left out. The labelling is noisy (a murder appeal that also discusses common intention gets one class only), so the scores measure how far the topical clusters line up with the main offence, not whether they are right.

| purity | NMI | Rand index | pair precision | pair recall | F1 | F5 |
|---|---|---|---|---|---|---|
| 0.4011 | 0.2643 | 0.8098 | 0.2289 | 0.2251 | 0.2270 | 0.2252 |

Pair counts: TP 227906, FP 767607, FN 784773, TN 6382534. The class sizes are very uneven (murder is the dominant offence of about a third of the labelled judgments), which keeps purity and RI high even for weak clusterings; NMI and F are the more telling numbers.
